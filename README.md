
# 🤖✨ 구미 캠퍼스 식단 알리미봇 등장! ✨🤖
안녕하세요, 여러분!
매일 점심, 저녁 메뉴를 앱으로 확인하기 번거로우셨죠?
<br>
이제 **Mattermost**에서 아주 똑똑하고 편리하게 식단을 받아보세요!


⏰ **자동 알림**: 매일 오전 8시 50분 (점심), 오후 2시(저녁)에 그날의 메뉴 사진을 채널에 자동으로 보내줘요!
<br>
🙋‍♂️ **원할 때 바로 확인**: 자동 알림 시간을 놓쳤어도 괜찮아요! 채팅창에 명령어를 입력하면 언제든지 메뉴를 다시 불러올 수 있어요.
<br>
📅 **내일 메뉴 조회**: "내일은 뭐 나오지?" 궁금할 땐, 내일 메뉴도 미리 확인할 수 있어요!
<br>
📊 **주간 메뉴 요약**: !주간메뉴 명령어 하나로, 이번 주 식단 전체를 한눈에 볼 수 있는 표를 만들어줘요.
<br>


### ⌨️ 명령어 사용법
채팅창에 아래처럼 입력해보세요!
<br>
**!점심** : 오늘 점심 메뉴를 바로 보여줘요.
<br>
**!저녁** : 오늘 저녁 메뉴를 바로 보여줘요.
<br>
**!내일점심**  : 내일 점심 메뉴를 미리 알려줘요.
<br>
**!내일저녁**  : 내일 저녁 메뉴를 미리 알려줘요.
<br>
**!주간메뉴** : 이번 주 월요일부터 금요일까지의 점심/저녁 메뉴 전체를 표로 요약해줘요.
<br>


구미 패밀리 여러분의 편리한 SSAFY 생활을 위해 태어난 식단 알리미 봇, 많이 이용해주세요!
